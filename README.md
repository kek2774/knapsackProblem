# Задача о рюкзаке

Курсовая работа по программированию: приложение для исследования и сравнения алгоритмов решения задачи о рюкзаке.

Проект состоит из графического интерфейса на Python/Flet и C++ модуля, подключенного к Python через pybind11. C++ часть отвечает за генерацию данных и выполнение алгоритмов, а Python часть показывает результаты в виде таблиц, графиков и гистограмм.

## Возможности

- сравнение точного алгоритма динамического программирования и жадного алгоритма;
- измерение времени работы алгоритмов на разных размерах входных данных;
- расчет итоговой ценности выбранных предметов;
- расчет погрешности жадного алгоритма относительно точного решения;
- построение графиков времени, ценности, количества выбранных предметов и ошибки;
- отображение гистограмм весов и ценностей;
- поддержка нескольких типов распределения входных данных.

## Установка и запуск

### 1. Клонировать репозиторий

```bash
git clone https://github.com/kek2774/knapsackProblem.git
cd knapsackProblem
```

### 2. Создать виртуальное окружение

Windows PowerShell:

```powershell
python -m venv .venv
```

### 3. Активировать виртуальное окружение

Windows PowerShell:

```powershell
.\.venv\Scripts\Activate.ps1
```

После активации в начале строки терминала обычно появляется `(.venv)`.

### 4. Установить зависимости

```powershell
pip install -r requirements.txt
```

Эта команда установит все библиотеки, перечисленные в `requirements.txt`.

### 5. Собрать C++ модуль

Для сборки нужен установленный компилятор C++. На Windows удобно использовать **x64 Native Tools Command Prompt for VS 2022** или другой терминал, где доступен компилятор Visual Studio.

```powershell
python setup.py build_ext --inplace
```

После успешной сборки в папке проекта появится файл C++ расширения, например:

```text
knapsack_cpp.cp313-win_amd64.pyd
```

Точное название файла может отличаться в зависимости от версии Python и операционной системы.

### 6. Запустить приложение

```powershell
python proga.py
```

## Описание алгоритмов

В проекте рассматривается классическая задача о рюкзаке: нужно выбрать набор предметов с максимальной суммарной ценностью так, чтобы их общий вес не превышал вместимость рюкзака.

Сравниваются два подхода:

- **Динамическое программирование** - точный алгоритм, который находит оптимальное решение;
- **Жадный алгоритм** - быстрый приближенный алгоритм, который выбирает предметы по вычисленному приоритету.

Результаты сравниваются по времени работы, итоговой ценности, количеству выбранных предметов и проценту ошибки относительно точного решения.

## Параметры эксперимента

В текущей версии используются следующие параметры:

- вместимость рюкзака: `400`;
- диапазон весов предметов: от `1` до `350`;
- размеры наборов данных: от `1` до `10 000 000` предметов;
- seed генератора случайных чисел: `225`.

## Типы распределений

Приложение поддерживает несколько вариантов генерации предметов:

- равномерное распределение;
- обратная зависимость;
- прямая зависимость;
- хаотичное распределение.

## Важное примечание

Собранный файл C++ расширения (`*.pyd`, `*.so`) не хранится в репозитории. Он зависит от операционной системы, версии Python и компилятора, поэтому после скачивания проекта его нужно собрать локально:

```powershell
python setup.py build_ext --inplace
```

Если при запуске появляется ошибка `ModuleNotFoundError: No module named 'knapsack_cpp'`, значит C++ модуль еще не собран или сборка завершилась с ошибкой.
