# Задача о рюкзаке

Курсовая работа по программированию: исследование алгоритмов решения задачи о рюкзаке с визуальным сравнением результатов.

Проект объединяет Python-интерфейс на Flet и C++ модуль, подключенный через pybind11. C++ часть выполняет генерацию данных и расчеты, а Python часть отображает таблицы, графики и сравнение алгоритмов.

## Что умеет программа

- сравнивает точный алгоритм динамического программирования и жадный алгоритм;
- измеряет время работы алгоритмов на разных объемах данных;
- считает итоговую ценность выбранных предметов и относительную погрешность;
- строит графики времени, ценности, количества выбранных предметов и ошибок;
- показывает гистограммы весов и ценностей входных данных;
- поддерживает несколько типов распределения предметов:
  - равномерное;
  - обратная зависимость;
  - прямая зависимость;
  - хаотичное распределение.

## Установка и запуск

### 1. Клонировать репозиторий

```bash
git clone https://github.com/kek2774/knapsackProblem.git
cd knapsackProblem
```

### 2. Создать и активировать виртуальное окружение

Windows PowerShell:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

### 3. Установить зависимости

```powershell
pip install flet flet-charts matplotlib numpy pybind11 setuptools
```

### 4. Собрать C++ модуль

Для сборки на Windows желательно открыть **x64 Native Tools Command Prompt for VS 2022** или терминал, где доступен компилятор C++.

```powershell
python setup.py build_ext --inplace
```

После успешной сборки в папке проекта появится файл вида:

```text
knapsack_cpp.cp313-win_amd64.pyd
```

Название может отличаться в зависимости от версии Python и операционной системы.

### 5. Запустить приложение

```powershell
python proga.py
```

## Основная идея

Задача о рюкзаке состоит в выборе набора предметов с максимальной суммарной ценностью при ограниченной вместимости рюкзака.

В проекте сравниваются два подхода:

- **динамическое программирование** - точный метод, который находит оптимальный ответ;
- **жадный алгоритм** - быстрый эвристический метод, который выбирает предметы по вычисленному приоритету.

Сравнение проводится по времени работы, итоговой ценности, количеству выбранных предметов и погрешности относительно точного решения.

## Параметры эксперимента

В текущей версии используются следующие настройки:

- вместимость рюкзака: `400`;
- диапазон весов предметов: от `1` до `350`;
- размеры наборов данных: от `1` до `10 000 000` предметов;
- фиксированный seed генератора: `225`.

## Примечание

Собранный файл C++ расширения (`*.pyd`, `*.so`) не хранится в репозитории, потому что он зависит от операционной системы, версии Python и компилятора. Поэтому после скачивания проекта модуль нужно собрать локально командой:

```powershell
python setup.py build_ext --inplace
```
